# v2.3 Compliance & Security — Detailed Build

## Goal
Prepare the platform for formal security/privacy assessment before handling production cross-border healthcare data.

## Workstreams
- Threat model and data-flow inventory
- PHI/PII classification
- Access-control matrix
- Audit-log retention policy
- Encryption at rest/in transit review
- Secrets management
- Key rotation
- Backup and restore testing
- Incident response runbook
- Vendor security/BAA review
- Data retention/deletion workflows
- Consent and privacy notices
- Security headers and dependency scanning
- Penetration-test remediation tracking

## Gate
No production PHI should be introduced merely because these controls exist. Production launch requires legal/compliance review for the jurisdictions served, healthcare-provider licensing requirements, privacy obligations, vendor contracts, and applicable security controls.
