# v2.0 Production Readiness

## Scope
- Production identity and access controls
- Managed secrets and key rotation
- Encryption at rest/in transit
- Secure object storage
- Audit logging and retention
- Monitoring, alerting and incident response
- Backups and disaster recovery
- Security assessment and penetration testing
- Privacy/compliance review
- Vendor due diligence
- Production deployment and rollback strategy

## Release gate
No production launch until security, privacy, healthcare/legal, payment, data-retention, provider, and operational reviews are explicitly approved. Development and test environments use synthetic data.
